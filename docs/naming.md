# Writing Conventions

This repository uses a simple and durable convention to keep all writing projects organized.

## Folder conventions

- `projects/`: each project is a separate novel or series
- `templates/`: reusable writing templates
- `library/`: reusable inspiration and world materials
- `tools/`: checklists, timelines, and writing aids
- `docs/`: repository workflow documentation

## File naming conventions

Use simple, searchable names:

- `01-opening.md`
- `02-the-escape.md`
- `03-false-trust.md`
- `character-01-lin.md`
- `world-01-city.md`

Avoid:

- vague names like `draft.md`
- unstructured naming
- mixing character files and world files in the same folder

## Chapter conventions

- use sequential numbering
- keep chapter names brief but descriptive
- one chapter = one file
- keep notes in `notes/`, not inside chapter folders if temporary

## Project conventions

Each project should ideally include:

- project README
- outline
- character index
- world overview
- chapter folder
- notes folder
- references

## Content conventions

- Keep plot notes separate from polished prose
- Use markdown for structure and readability
- Keep metadata at the top of files
- Track major story changes in the timeline
