# Writing Workflow

This document describes the workflow for managing multiple projects in the repository.

## 1. Start a new project

Create a project folder under `projects/`:

```text
projects/
├── fantasy-epic/
├── cyberpunk-story/
├── romance-series/
└── ...
```

Each project should include:

- `README.md`
- `outline.md`
- `characters/`
- `world/`
- `chapters/`
- `notes/`
- `references/`
- `timeline.md`

## 2. Before writing

Before drafting chapters, define:

- core premise
- target audience
- main theme
- central conflict
- key characters
- setting and tone

## 3. Drafting discipline

- Write scenes in chronological order when possible
- Keep notes and rough drafts separate from polished files
- Number chapters consistently
- Treat worldbuilding as a support layer, not a distraction

## 4. Revision loop

Recommended cycle:

1. outline
2. scene list
3. first draft
4. structural revision
5. line-level polish
6. consistency review
7. final pass

## 5. Project health tracking

Use `timeline.md` to record:

- start date
- milestones
- chapter completion
- major plot decisions
- revision rounds

## 6. Scale-up

When multiple projects accumulate, use `library/` and `tools/` to keep reusable structure:

- idea bank
- scene notes
- writing prompts
- release checklist
- common templates
