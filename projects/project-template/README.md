# Project Template

This folder is a starter template for a new novel project.

## Structure

```text
project-template/
├── README.md
├── outline.md
├── timeline.md
├── characters/
│   └── README.md
├── world/
│   └── README.md
├── chapters/
│   └── README.md
├── notes/
│   └── README.md
├── references/
│   └── README.md
└── ...
```

## Suggested workflow

1. Start with `outline.md`
2. Build character and world files
3. Draft chapter files in the `chapters/` folder
4. Keep rough ideas in `notes/`
5. Maintain milestone tracking in `timeline.md`
