# Writing Checklist

## Before drafting

- [ ] Project premise clear
- [ ] Story goal defined
- [ ] Main characters mapped
- [ ] Major conflict identified
- [ ] World rules set

## During drafting

- [ ] Chapter plan complete
- [ ] Scenes flowing logically
- [ ] Stakes rising steadily
- [ ] Character arcs moving

## Before finalizing

- [ ] Continuity checked
- [ ] Dialogue reviewed
- [ ] Descriptions trimmed
- [ ] Ending resolves main conflict
